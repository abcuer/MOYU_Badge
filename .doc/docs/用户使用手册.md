# MoYu Badge 用户使用手册

## 1. 首次使用

1. 设备上电后会优先尝试连接已保存的 Wi-Fi。
2. 如果没有可用网络，设备会进入 AP 配网模式。
3. 手机连接热点 `MoYu_Modge`。
4. 浏览器访问 `192.168.100.1`。
5. 选择目标 Wi-Fi 并输入密码，等待设备完成连接。

## 2. 基础交互方式

- 短按：切换、下一项、开始。
- 长按：确认、进入、执行当前操作。
- 超长按：退出当前模式。
- 倾斜设备：在部分模式下用于调节音量或控制游戏。

## 3. 页面说明

### 3.1 主时钟页

- 显示时间、天气、室温、气压和海拔。
- 长时间无操作会自动休眠。

### 3.2 应用选择页 / 游戏选择页

- 短按切换条目。
- 长按进入条目。
- 空闲时会自动休眠。

### 3.3 电台模式

- 短按：切换电台。
- 长按：进入或退出音量调节。
- 音量调节状态下：左右倾斜设备调节音量。
- 超长按：退出电台并回到选择菜单。

补充说明：

- 如果电台正在播放且一段时间没有按键输入，系统会自动熄灭 OLED。
- 息屏期间电台后台播放、网络连接和音频任务会继续工作。
- 按任意键会先亮屏，再执行后续操作。

### 3.4 录音机模式

- 第一次短按：删除上一段录音并开始新录音。
- 第二次短按：结束录音并自动播放一次。
- 长按：播放当前录音。
- 超长按：退出录音机并回到选择菜单。

### 3.5 血氧模式

- 将手指稳定贴合 `MAX30102` 传感器。
- 测量期间尽量避免移动手指和设备。
- 结果仅供参考，不作为医疗依据。

### 3.6 系统设置

- 系统信息
- 音量调节
- Wi-Fi 重置
- 退出设置

## 4. 休眠与息屏

- 主时钟页、应用选择页、游戏选择页、系统信息页支持自动休眠。
- 电台模式为仅息屏，不会停止后台播放。
- 唤醒后设备会恢复到之前所在页面。

## 5. Wi-Fi 重置

如果设备保存的是旧环境 Wi-Fi，可通过以下方式清除并重新配网：

- 同步 / 配网页面长按。
- 系统设置中的 Wi-Fi 重置页面。
