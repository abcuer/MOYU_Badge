## 🛠️ 核心技术栈

* **核心主控**：ESP32-S3 (双核 Tensilica LX7，支持 Wi-Fi & BLE)
* **实时内核 (RTOS)**：原生 FreeRTOS（任务并发、二值信号量、状态机事件组）
* **物联网生态 (IoT)**：标准 MQTT 协议，无缝对接移动 OneNET 平台，3s 级高频数据上报
* **功耗管理 (Low Power)**：Deep-sleep 深度休眠 + 传感器同步挂起软件 Sleep + GPIO 外部中断唤醒
* **开发环境**：VS Code + ESP-IDF (Espressif IoT Development Framework)

---

## 🧠 系统架构 (FreeRTOS 机制)

项目核心基于 FreeRTOS 实现多任务并发、资源同步与状态阻塞，避免 CPU 空转：
* **任务调度 (Task Scheduling)**：多任务并行（UI 刷新、传感器数据轮询、MQTT 状态机上报）。
* **信号量 (Semaphore)**：用于按键状态的高效传递（消除传统的软件死循环轮询，降低 CPU 占用率）。
* **事件组 (Event Groups)**：用于 Wi-Fi 连接、NTP 同步、OneNET 平台连接等多状态联合同步。

* **显示**：0.96 寸 OLED 屏幕 (I2C 接口)

| **生物检测** | MAX30102 | 采集心率、血氧饱和度 (SpO2) 数据，支持软件休眠 |

## 🚀 核心功能拆解

### 📶 1. 网络、NTP 与 OneNET 云端同步 (MQTT)
* **SmartConfig / AP 配网 / WIFI 重置**
    * 新设备首次开机自动进入配网模式。配网成功后通过 NVS (非易失性存储) **自动保存**，后续开机自动回连。处于同步页面时可长按按键**重置 WIFI**。
* **OneNET 数据上报 (MQTT 异步通信)**
    * 系统连接网络后，每隔 **3秒** 自动向 OneNET 平台推送全量信息包：设备城市、时空信息（日期、室外天气、室外温度）、室内环境（温度、气压）及生物健康数据（实时心率、血氧浓度）。

### 🔋 2. 智能低功耗与电源管理 (PM)
* **无操作自动休眠**：设备在无交互一段时间后自动进入休眠模式。
* **传感器同步挂起**：休眠前，主控通过 I2C 指令将 MPU6050、BMP280、MAX30102 等传感器同步切入 Sleep 状态，最大化节省电池电量。
* **外部按键唤醒**：支持通过物理按键触发 GPIO 中断唤醒。唤醒后系统瞬间恢复，自动重连 Wi-Fi，秒级更新网络状态与云端数据。

### 💻 3. UI 界面与多线程交互（非阻塞式状态机）

* 🛰️ **Wi-Fi 与 NTP 同步页**：滚动显示 `Syncing...` 状态、实时计时（秒）、随机励志短句。底部基于正弦映射实现单摆球非阻塞 Loading 动效。
* 🏠 **主时钟页**：显示实时时间、Wi-Fi 状态、室内温度（BMP280）与当地海拔。
* ❤️ **血氧检测页**：高频采集 MAX30102 数据，OLED 逐点实时绘制心率波形曲线。
* 🎮 **体感游戏中心**：利用 MPU6050 姿态解算，实现 **悬浮球（重力平衡）**、**恐龙快跑（按键跳跃/蹲下）**、**飞机大战（俯仰位移击杀）**。
* ℹ️ **系统与作者信息**：显示 B 站与 GitHub 账号，支持一键随机切换极客语录彩蛋。

## 🗺️ 未来规划 (Roadmap & 进阶功能预留)

> 为充分榨干 ESP32-S3 的双核性能与 I2S/Audio 特性，后续迭代版本将解锁以下重磅功能：

### 🎙️ 1. 接入 AI 小智（智能离线语音与大模型对话）
* **离线语音唤醒**：基于 `ESP-SR` 组件，本地化识别免唤醒词。
* **大模型流式对话**：接入千问/DeepSeek/豆包等大语言模型，利用 ESP32 的 Wi-Fi 流式传输能力进行智能对话。

### 🎵 2. Wi-Fi 网络流媒体电台
* **音频输出 (I2S 驱动)**：硬件预留 I2S 接口接入外部 DAC (如 MAX98357A / PCM5102A) 驱动扬声器。
* **网络音频解码**：支持通过 Wi-Fi 实时拉取 HTTP 协议的音频流（MP3/AAC），解析并实时播放网络电台音乐。
