# ESP32-S3 多功能工牌

基于 ESP32-S3 的工牌项目，当前版本包含时钟显示、血氧/心率检测、体感游戏、网络电台、Wi-Fi 配网、OneNET 上报与 OTA 基础能力。

## 项目简介

这个项目基于 ESP-IDF 和 FreeRTOS 开发，围绕一块带 OLED 屏幕、姿态传感器、环境传感器、生物传感器和音频输出的 ESP32-S3 工牌板卡展开。项目当前重点是把多模式 UI、联网能力、音频播放、传感器采集和基础 OTA 能力整合到同一套固件中。

## 功能简介

### 当前已实现功能

- Wi-Fi 自动连接与 AP 配网
- captive portal 配网页面，设备热点默认访问地址为 `192.168.100.1`
- 主时钟页面，显示时间、天气、室内温度和海拔
- 血氧/心率检测页面
- 体感游戏入口与 3 个游戏模式：悬浮球、恐龙、飞机
- 网络电台模式
- 系统设置页面与音量调节
- 电台页面内长按进入调音，倾斜调节音量
- OneNET MQTT 数据上报
- HTTPS OTA 基础能力
- 部分页面长时间无操作自动休眠
- 自动休眠时会关闭 OLED、让部分传感器进入休眠，并暂停部分后台任务
- WS2812 状态灯在部分模式下联动显示状态

### 当前主要页面/模式

- `主时钟`
- `血氧检测`
- `应用选择`
- `网络电台`
- `系统设置`
- `悬浮球`
- `恐龙`
- `飞机`


## 开发说明


### 开发环境

- ESP-IDF
- FreeRTOS
- VS Code

### 当前工程要点

- UI 与业务逻辑围绕多模式状态切换实现
- 传感器采集、显示刷新、按键扫描、云端上报分别由独立任务处理
- Wi-Fi、时间同步和部分联网能力通过事件组协同
- 网络电台基于 HTTP 音频流播放
- OTA 采用双 OTA 分区 + HTTPS OTA

### 当前使用到的 FreeRTOS 功能

- `任务（Task）`：用于拆分 OLED 刷新、传感器采集、按键扫描、时间同步、OneNET 上报等并发工作
- `事件组（Event Group）`：用于协调 Wi-Fi 连接、时间同步等状态等待与通知
- `信号量 / 互斥量（Semaphore / Mutex）`：用于控制 Wi-Fi 扫描流程，以及保护电台音频缓冲区和音频输出访问这类共享资源
- `任务延时（vTaskDelay）`：用于周期采样、界面刷新和轮询节流
- `任务挂起 / 恢复（vTaskSuspend / vTaskResume）`：用于部分休眠流程中的任务暂停与恢复

### 低功耗设计

- 当前工程实现的是 `light sleep` 级别的空闲休眠
- 在主时钟、应用选择、系统设置等页面长时间无操作时，设备会进入自动休眠
- 进入休眠前会关闭 OLED 显示、让 `MPU6050`、`BMP280`、`MAX30102` 进入休眠，并暂停部分后台任务
- 设备通过按键 GPIO 唤醒，唤醒后会恢复显示、传感器和被暂停的任务
- 电台、血氧、游戏、配网等流程默认不会因为短时间无操作自动进入休眠


### 当前分区与联网能力

- 分区表已使用双 OTA 分区
- 已接入 OneNET MQTT
- 已接入 HTTPS OTA 基础能力
- 已支持 AP 配网与保存 Wi-Fi 凭据

### 开发时需要注意

- 修改 OTA 相关逻辑时，需要同时确认分区表、启动确认逻辑和下载链接可用性
- 修改电台相关逻辑时，需要同时关注网络状态、音量保存和音频输出硬件
- 修改血氧相关逻辑时，建议在真实佩戴场景下验证，不要只看静态代码
- README 中如果新增功能描述，应以仓库当前可运行代码为准，不写未实现内容

## 用户使用守则

### 首次配网

1. 设备首次启动后会进入 AP 配网模式。
2. 手机连接设备热点。
3. 在浏览器访问 `192.168.100.1`。
4. 选择要连接的 Wi-Fi 并输入密码。
5. 配网成功后，设备会保存 Wi-Fi 信息，后续开机会自动尝试连接。

### 已保存 Wi-Fi 在新环境失效时

- 如果设备保存的是旧环境 Wi-Fi，到了新环境可能无法联网。
- 项目当前支持清除已保存 Wi-Fi 后重新进入配网。
- 在配网/同步提示页面可通过长按按键执行 Wi-Fi 重置。
- 若设备停留在配网页或同步页，请先确认是否已经清除了旧 Wi-Fi 配置。

### 电台模式使用说明

- 短按：切换电台
- 长按：进入或退出电台内音量调节
- 调音状态下：左倾减小音量，右倾增大音量
- 超长按：退出电台，回到应用选择页

使用注意：

- 电台功能依赖网络连接
- 需要音频输出硬件正常工作，才会有声音
- 电台音量会在退出调音时保存

### 血氧检测使用说明

- 测量时请将手指稳定贴合 MAX30102 传感器
- 测量过程中尽量不要晃动设备或手指
- 强环境光、佩戴方式不稳定、手指接触不良都会影响结果
- 若页面长时间没有数值，请重新贴合手指并保持静止
- 血氧与心率结果仅供参考，不作为医疗依据

### 自动休眠说明

当前代码中，以下页面长时间无操作会进入休眠：

- 主时钟页
- 应用选择页
- 系统设置页

进入休眠时，设备会关闭 OLED、暂停部分后台任务，并让部分传感器进入休眠；按键可将设备唤醒。

以下页面默认不会因为短时间无按键而自动休眠：

- 血氧检测页
- 网络电台页
- 游戏页
- 首次配网/同步相关流程

### OTA 使用前提与限制

- 项目当前已经接入双 OTA 分区和 HTTPS OTA 基础能力
- 第一次使用 OTA 前，需要先完整刷写一次当前固件，因为分区表已经切换为双 OTA 布局
- 当前 OTA 通过 OneNET OTA 通知触发，并执行 HTTPS 下载升级
- OTA 使用时需要设备已经联网
- OTA 链路是否成功，还取决于固件下载地址、证书链和服务器可访问性

## 硬件与交互说明

### 当前使用的硬件模块

| 模块 | 作用 |
| --- | --- |
| ESP32-S3 | 主控 |
| OLED 屏幕 | 显示 UI |
| MPU6050 | 姿态检测、体感输入 |
| BMP280 | 温度、气压、海拔 |
| MAX30102 | 心率、血氧检测 |
| MAX98357 | 电台音频输出 |
| WS2812 | 状态灯 |
| 独立按键 | 页面切换、确认、配网重置、电台交互 |

### 交互特点

- 单按键负责模式切换和确认操作
- 姿态输入主要用于游戏和电台/设置中的音量调节
- 电台模式内支持短按切台、长按调音、超长按退出
