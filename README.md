# MoYu Badge

基于 ESP32-S3 的多功能 Badge 固件项目，集成了时钟天气、血氧心率、体感游戏、网络电台、录音、Wi-Fi 配网、OneNET 上报和 OTA 等功能。

## 功能概览

### 核心功能

- Wi-Fi 自动连接与 AP 配网
- Captive Portal 配网页面，默认访问地址为 `192.168.100.1`
- 主时钟页，显示时间、天气、室内温度、气压和海拔
- 血氧 / 心率检测
- 体感游戏，包含悬浮球、恐龙、飞机 3 个模式
- 网络电台
- 录音与回放
- 系统设置与音量调节
- OneNET MQTT 数据上报
- HTTPS OTA 基础能力



### 页面与模式

- 主时钟
- 血氧检测
- 应用选择
- 游戏选择
- 网络电台
- 录音
- 系统设置
- 悬浮球
- 恐龙
- 飞机

## 开发手册

### 开发环境

- ESP-IDF 5.3.4
- FreeRTOS
- VS Code

### 常用命令

```bash
idf.py build
idf.py -p COMx flash monitor
```

### 项目结构

- `main/`：应用入口
- `components/app/`：UI、任务、模式切换、联网业务、录音、电台等上层逻辑
- `components/modules/`：传感器、OLED、IMU、音频等模块驱动
- `components/bsp/`：底层 BSP，例如 I2C、延时等
- `partitions_webserver.csv`：分区表

### 任务说明

- `start_oled_task`：页面绘制与刷新
- `start_sensor_task`：传感器按模式启停与采样
- `start_key_task`：按键扫描
- `start_sync_task`：联网后时间同步、天气拉取
- `start_onenet_task`：OneNET 周期上报

模式切换、休眠判断与唤醒恢复逻辑集中在 `components/app/mode/` 中。

### 低功耗说明

当前实现的是 `Light Sleep` 级别低功耗。

会自动休眠的页面：

- 主时钟页
- 应用选择页
- 游戏选择页
- 系统信息页

默认不会因短时间无操作自动休眠的流程：

- 血氧检测
- 网络电台
- 录音活跃状态
- 游戏过程
- 首次配网 / 同步流程

进入休眠前会：

- 关闭 OLED 显示
- 让 `MPU6050`、`BMP280`、`MAX30102` 进入休眠
- 暂停部分后台任务
- 配置按键 GPIO 作为唤醒源

唤醒后会：

- 恢复 OLED 显示
- 恢复休眠前的 UI 页面状态
- 按当前模式重新同步传感器电源状态
- 恢复被暂停的后台任务

### 传感器按模式启停

#### MPU6050

仅在以下场景启用：

- 悬浮球 / 恐龙 / 飞机游戏
- 设置页音量倾斜调节
- 电台页音量倾斜调节

#### BMP280

仅在主时钟页启用：

- 进入时钟页后按需测量
- 离开时钟页后进入休眠
- 当前使用 `forced mode` 单次测量

#### MAX30102

仅在血氧模式启用：

- 进入 `MODE_BLOOD` 时唤醒并恢复 SpO2 配置
- 离开 `MODE_BLOOD` 时立即休眠
- 模式切换时会重置血氧采样状态

### OLED 刷新策略

当前大致策略如下：

- 时钟页：`1000 ms`
- 应用选择 / 游戏选择 / 系统信息页：`200 ms`
- 设置普通页 / 电台普通页：`100 ms`
- 游戏、血氧、音量调节、录音活跃态：`30 ms`

### 联网与 OTA

当前项目已经接入：

- 双 OTA 分区
- HTTPS OTA 基础能力
- OneNET MQTT 属性上报

使用 OTA 前请确认：

- 已正确烧录当前完整固件
- 设备已联网
- 固件下载地址、证书链和服务器访问正常

## 用户使用手册

### 首次配网

1. 设备首次启动后进入 AP 配网模式
2. 手机连接设备热点
3. 浏览器访问 `192.168.100.1`
4. 选择要连接的 Wi-Fi 并输入密码
5. 配网成功后设备会保存 Wi-Fi 信息，后续自动重连

### 已保存 Wi-Fi 在新环境失效时

如果设备保存的是旧环境 Wi-Fi，到了新环境可能无法联网。

当前支持清除已保存 Wi-Fi 后重新配网：

- 在同步 / 配网相关页面长按按键可执行 Wi-Fi 重置
- 也可以在系统设置中进入 Wi-Fi 重置相关页面操作

### 电台模式使用说明

- 短按：切换电台
- 长按：进入或退出音量调节
- 音量调节状态下：通过倾斜调整音量
- 超长按：退出电台并回到应用选择页

### 血氧检测使用说明

- 将手指稳定贴合 `MAX30102`
- 测量时尽量不要晃动设备或手指
- 强环境光、接触不稳都会影响结果
- 结果仅供参考，不作为医疗依据

### 自动休眠说明

以下页面长时间无操作会进入休眠：

- 主时钟页
- 应用选择页
- 游戏选择页
- 系统信息页

按键可将设备唤醒，唤醒后会恢复到休眠前所在页面。

### 使用提示

- 电台、血氧、游戏、配网等流程默认不会因短时间无操作自动休眠
- 血氧模式下建议保持手指稳定贴合传感器
- 如果切换到新环境，请确认是否需要清除旧 Wi-Fi 配置
